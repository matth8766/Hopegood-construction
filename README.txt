HOPEGOOD CONSTRUCTION LTD. WEBSITE

This website is ready to upload to a static web host.

ESTIMATE FORM
The Request an Estimate form is connected to FormSubmit and sends submissions to:
mhopegood@gmail.com

IMPORTANT — ONE-TIME ACTIVATION
1. After the website is online, submit one test estimate through the form.
2. FormSubmit will email mhopegood@gmail.com asking you to activate the form.
3. Open that email and click the activation/confirmation link.
4. Submit another test form to confirm delivery.

The form accepts project details plus optional JPG, PNG and PDF uploads. FormSubmit currently limits the combined upload size to 10 MB.

WHEN THE BUSINESS EMAIL CHANGES
Replace mhopegood@gmail.com in the form action in contact.html with the new email address. FormSubmit will require another one-time activation for the new address.

PUBLISHING
Upload the CONTENTS of this folder to your web host so index.html is at the root of the site.

Files:
- index.html — home
- services.html — services
- projects.html — project gallery
- about.html — company/about
- contact.html — estimate request form
- styles.css — visual styling
- assets/ — logo and project photos
